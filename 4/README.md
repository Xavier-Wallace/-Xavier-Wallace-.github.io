# History and Legacy of the Divine Nine

## Project Description

This website explores the history and legacy of the nine historically Black Greek-letter organizations that make up the National Pan-Hellenic Council, also known as the Divine Nine.

## Website Pages

- `index.html` — Home page introducing the Divine Nine.
- `explore.html` — Interactive two-step experience for exploring topics and subtopics.
- `resources.html` — Educational resources and official organization links.
- `contact.html` — Feedback form demonstration.

## Project Files

- `css/styles.css` — Website styling and responsive layout.
- `js/explore.js` — JavaScript that handles the interactive choices.
- `data/exploreData.json` — JSON data containing topics, subtopics, and descriptions.

## Technologies Used

- JavaScript
